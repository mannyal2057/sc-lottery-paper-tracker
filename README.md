# SC Pick 3 and Pick 4 cloud paper tracker

This public package runs the locked South Carolina Pick 3 and Pick 4 paper studies on GitHub Actions at 9:05 a.m. and 3:05 p.m. America/New_York, then publishes the static dashboard through GitHub Pages. It uses public, no-login lottery, archive and weather sources. A laptop is not required after deployment.

All predictions are registered before the official cutoffs. Results remain pending until the official lottery page and independent archive agree. Forecasts, protocols, source snapshots and audit chains are retained in the repository. No tickets are purchased, FIREBALL is excluded and interim results do not establish a predictive advantage.

The workflow can also be started manually from the repository's Actions page.
